# Masjid Darul Ulum System Management

Welcome to the **Masjid Darul Ulum System Management** repository!  
This project is designed to help manage various administrative and informational aspects of Masjid Darul Ulum. Built primarily with CSS, HTML, and PHP, it offers a user-friendly interface and essential backend functionalities for efficient masjid management.

## Features

- **Masjid Event Management:** Add, edit, and display upcoming events.
- **Prayer Schedule:** Timely updates and display of daily prayer times.
- **Donation Tracking:** Record and manage donations for various masjid activities.
- **Announcements:** Post and manage important announcements for the community.
- **Admin Dashboard:** Secure area for authorized personnel to manage site content.
- **Responsive Design:** Optimized for all devices using modern CSS.

## Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Fadelnz/MasjidDarulUlum_systemManagement.git
   cd MasjidDarulUlum_systemManagement
   ```

2. **Set Up Server**
   - Ensure you have a local server (e.g., XAMPP, WAMP, MAMP) with PHP support.
   - Place the project files in the server's root directory (e.g., `htdocs` for XAMPP).

3. **Configure Database**
   - Create a MySQL database for the system.
   - Import any provided `.sql` files to set up tables and initial data.
   - Update database credentials in the PHP config files as needed.

## Usage

- Access the application via your browser (e.g., `http://localhost/MasjidDarulUlum_systemManagement/`).
- Use the admin dashboard for content management and data entry.
- Regular users can view announcements, events, and prayer times.
